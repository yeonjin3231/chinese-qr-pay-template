# 课堂支付 · 中国超市 — 중국어 수업용 QR 결제 체험 웹앱

중국어 수업에서 실제 화폐 없이 QR 결제 문화를 체험하는 교육용 웹앱입니다. 학생들은 클래스도조(ClassDojo) 등에서 받은 칭찬 포인트를 1점당 2위안(¥)으로 환전한 가상 잔액으로, 교실 상점에서 물건을 사고팔며 QR 결제와 중국어 회화를 함께 연습합니다.

> 이 저장소는 **선생님마다 각자 자기 계정에 배포해서 쓰는 템플릿**입니다. 학생 명단·잔액·거래 기록은 코드가 아니라 각자의 Netlify 계정 안에 별도로 저장되므로, 여러 학교가 각자 이 템플릿으로 배포하면 서로의 데이터는 완전히 분리됩니다.

## 미리 보기
데모: https://chineseqrpay.netlify.app (CNSA 실 사용 사이트 — 다른 학교는 아래 방법으로 각자 배포해서 쓰세요)

## 내 계정에 배포하기 (약 5분)

### 1) 원클릭 배포
아래 버튼을 누르면 Netlify가 이 저장소를 포크하고 자동으로 배포해줍니다. (Netlify 계정이 없으면 GitHub 계정으로 무료 가입 가능)

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/msimetc/chinese-qr-pay-template)

### 2) (권장) 관리자 PIN 직접 설정하기
기본 관리자 PIN은 `2026`입니다. 그대로 써도 되지만, 내 계정에서는 다른 값으로 바꾸는 걸 권장합니다.
1. Netlify 사이트 대시보드 → **Site configuration → Environment variables**
2. 새 변수 추가: `TEACHER_PIN` = 원하는 4자리 숫자
3. 저장 후 **Deploys → Trigger deploy**로 한 번 다시 배포

### 3) 바로 사용 시작
배포된 주소(`https://내사이트이름.netlify.app`)에서:
- **교사 관리** → PIN 입력 → "엑셀 업로드"에서 클래스도조 성적표(엑셀/CSV) 업로드 → 학생 명단 완성
- 학생들에게 주소를 공유하면 각자 반(팩) 선택 → 이름 선택 → 처음 로그인 시 PIN 직접 설정

사용법 전체는 아래 "사용 설명서"를 참고하세요.

## 핵심 기능
- 교사 화면에서 엑셀/CSV 업로드 → 즉시 학생 명단·잔액 반영 (코드에는 학생 정보가 전혀 저장되지 않음)
- 클래스도조 포인트 1점당 2위안 자동 환전
- 학생이 첫 로그인 시 직접 4자리 PIN 설정 (교사가 임의로 지정하지 않음)
- 결제 전 상황별 중국어 회화(한어병음 포함) 추천 화면
- QR 스캔 또는 수동 금액 입력 결제
- 교사 대시보드: 학생 추가/수정/삭제, PIN 보기·초기화, 거래 확인·취소, 전체 초기화
- Netlify Functions + Netlify Blobs로 학생·교사 화면이 공유 서버 저장소를 사용 (몇 초 간격 자동 동기화 — 학생이 결제하면 잠시 후 교사 화면에도 반영)

## 명단 업로드 형식
첫 줄(헤더)에 다음 열이 있어야 합니다.
| 구분 | 인식되는 열 이름 |
|---|---|
| 이름 (필수) | 이름 / 학생 / 성명 / name |
| 포인트 | 포인트 / 보상 / 점수 / 도조 / points / score |
| 팩(반) — 선택 | 팩 / 반 / pack / class |

같은 팩을 다시 업로드하면 그 팩의 기존 명단만 새 내용으로 교체되고, 다른 팩은 그대로 유지됩니다.

## 로컬 개발
정적 웹앱 + Netlify Functions 구조입니다. 별도 빌드 도구(Vite 등) 없이 `index.html` / `app.js` / `styles.css`를 직접 수정하면 됩니다.
```
npm install
netlify dev      # 환경에 따라 동작하지 않을 수 있음 (로컬 워커 스레드 이슈)
netlify deploy --build         # 미리보기(draft) 배포
netlify deploy --prod --build  # 실제 서비스 배포
```
